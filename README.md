# Лабораторные работы по основам программирования и алгоритмизации

**Выполнила:** Селиверстова Анжелика Владимировна  
**Группа:** ПМ-2602

В этом репозитории собраны лабораторные работы по дисциплине «Основы программирования и алгоритмизации». Каждая работа находится в отдельной папке вместе с программой на Java и отчётом.

| Работа | Тема | Отчёт | Программа |
|---|---|---|---|
| Лабораторная работа № 1 | Определение участка числовой прямой | [Lab1/README.md](Lab1/README.md) | [Lab1/Main.java](Lab1/Main.java) |
| Лабораторная работа № 2 | Обработка массива натуральных чисел | [Lab2/README.md](Lab2/README.md) | [Lab2/Main.java](Lab2/Main.java) |

## Запуск программы

Перейдите в папку нужной лабораторной работы и выполните команды:

```text
javac Main.java
java Main
```

Описание входных данных и примеры работы программы находятся в README соответствующей лабораторной работы.
